# Data Science Projects – RWTH Aachen

This repository contains a comprehensive collection of data science projects developed as part of the *Introduction to Data Science* course at RWTH Aachen University.

---

## 📌 Project Overview

The repository is structured into two main parts:

### 📊 Part 1 – Medical Insurance Data Analysis
Focus: Core Data Science & Machine Learning

- Exploratory Data Analysis (EDA)
- Feature engineering & data preprocessing
- Classification (Decision Trees, SVM)
- Regression (Linear Regression)
- Clustering (K-Means)
- Neural Networks (MLP)
- Model evaluation & interpretation

---

### 🧠 Part 2 – Advanced Data Science Applications
Focus: Specialized & Real-World Data Problems

- Market Basket Analysis (association rules, FP-Growth)
- Process Mining (event logs, Petri nets, conformance checking)
- Natural Language Processing (tokenization, n-grams, TF-IDF retrieval)
- Time Series Analysis & Forecasting (ARIMA, seasonality, STL)
- Distributed Data Processing (Apache Spark, MapReduce)


---

## 🛠️ Technologies & Tools

- Python (pandas, numpy)
- scikit-learn
- matplotlib / seaborn
- NLTK (NLP)
- statsmodels / sktime (time series)
- pm4py (process mining)
- Apache Spark (PySpark)

---

## 🎯 Key Skills Demonstrated

- Data cleaning & preprocessing
- Exploratory data analysis & visualization
- Supervised & unsupervised learning
- Model evaluation & comparison
- Natural language processing
- Time series modeling & forecasting
- Process mining & event log analysis
